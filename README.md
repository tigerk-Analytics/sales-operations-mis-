SALES & OPERATIONS MIS PROJECT

Project Title:
Sales & Operations MIS Reporting System

Business Scenario:
A mid-sized distribution company wants a monthly MIS system to track sales,
targets, employee performance, product performance and order status.

Files:
1. Sales_Operations_MIS_Project.xlsx
2. MIS_Raw_Data.csv

Excel Sheets:
- Raw_Data: 1,200 operational records
- Monthly_MIS: monthly sales vs target
- Employee_MIS: employee performance and ranking
- Product_MIS: product sales and units

Key KPIs:
- Total Sales
- Target
- Achievement %
- Target Variance
- Total Orders
- Average Order Value
- Completed / Pending / Cancelled Orders

Resume Project Description:
Sales & Operations MIS Dashboard | Excel, Power BI, SQL
• Built a sales and operations MIS reporting system using 1,200+ records.
• Prepared monthly sales, target achievement, variance and employee performance reports.
• Created KPI dashboard to track sales, orders, achievement %, pending and cancelled orders.
• Used Excel PivotTables, lookup/formula-based reporting and dashboard visualizations.

Interview Questions:
1. What was the purpose of the MIS?
Answer: To convert raw operational data into regular management reports for tracking
sales, targets, employee performance and order status.

2. What KPIs did you track?
Answer: Sales, target, achievement %, variance, orders, average order value,
completed orders, pending orders and cancellations.

3. How did you calculate achievement?
Answer: Sales divided by target multiplied by 100.

4. What would you do if management asks for a new KPI?
Answer: First define the business requirement and calculation, validate the source
fields, add the calculation to the reporting layer, test it against sample records,
then include it in the dashboard.

5. What is the difference between MIS and Data Analytics?
Answer: MIS focuses heavily on recurring operational reporting, monitoring and
decision support. Data Analytics can go deeper into trends, causes, forecasting
and exploratory analysis.

6. How would you update this report every month?
Answer: Append validated new records to the source data, refresh the calculations/
PivotTables, check data quality, verify totals against the source and publish the
updated dashboard.

7. What data-quality checks would you perform?
Answer: Duplicate Order IDs, blank employee/product fields, invalid dates,
negative or zero values where not expected, incorrect targets and inconsistent
status values.

8. How would you explain a low achievement percentage?
Answer: I would first verify the data, then break the variance down by employee,
region, product and month to identify where the shortfall is concentrated.
